#TEXT-TO-SPEECH

A very simple and lightweight Text-to-Speech (TTS) and Speech-to-Text program built using the pyttsx3 library in Python. This script converts text into spoken audio and speech into text directly on the device without requiring an internet connection.
It demonstrates how to initialize the TTS engine, speak a custom message, STS writes and safely release resources. It also illustrates the foundation of modern AI assistants and helps to understand them.

FEATURES

1. Offline text-to-speech and speech-to-text(works without internet)

2. Customizable voice output

3. Beginner-friendly and easy to extend

TECH STACK

1. Python 3

2. pyttsx3 (text-to-speech engine)

USE CASE

1. Learning & fun experiments
